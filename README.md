# MTD-Toolkit
This is the software platform for MTD Design Studio Toolkit
MTD Design Studio is a calculation toolkit for programming microscale temperature differential design. This platform is developed to predict and optimize local temperature gradients generated by ferromagnetic particles under an alternating magnetic field. The software provides three main modules:
(A) Temperature Gradient Prediction
(B) Temperature Gradient Design
(C) Update Database
The current built-in database supports ferromagnetic metals including Co, Fe, and Ni.

## (A) Temperature Gradient Prediction Module
Temperature Gradient Prediction Module is used to predict the microscale temperature gradient under given operating and material parameters. Input parameters include magnetic flux density (B, mT), particle radius (R, mm) and ferromagnetic metal type (Co or Fe or Ni). Output results include predicted temperature gradient parameters such as average hot particle temperature, average cold particle temperature and temperature gradient.
How to use:
(1) Select the ferromagnetic metal.
(2) Enter the magnetic flux density B (mT) and the particle radius R (mm).
(3) Click Start Calculation.
(4) Review the predicted temperature gradient and corresponding output data.

## (B) Temperature Gradient Design Module
Temperature Gradient Design Module is used for inverse temperature gradient design. The user enters a target ferromagnetic metal and desired temperature gradient, and toolkit searches for suitable operating parameters. Input parameters include ferromagnetic metal type (Co or Fe or Ni) and target temperature gradient (averaged hot particle and cold particle temperatures). The toolkit will search for the optimized magnetic flux density B and particle radius R with accuracy.
How to use:
(1) Select the ferromagnetic metal.
(2) Enter the target hot particle and cold particle temperatures.
(3) Click Start Calculation.

## (C) Update Database
Update Database Module allows users to update the database and retrain the prediction model with new experimental or simulation data. The users can download the standard data template, upload new experimental or simulation data and refit the prediction model.
How to use:
(1) Click Download Template to obtain the standard data format.
(2) Fill in the new data according to the required columns.
(3) Upload the completed data file.
(4) Click Update Database.The software will check the data format and refit the model.
